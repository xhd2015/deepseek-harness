# 重复指定 Web 绑定地址

[English](guide.md) | 中文

## 变更

此前，Web 命令重复指定 `--host` 时只保留最后一个值。现在每个参数都为同一个 DSH 运行时增加一个监听器，共享端口、路由状态和认证服务。任一地址不可用或端口被占用都会使启动失败，并回滚整组监听器。不指定地址或只指定一个地址的命令保持原有暴露范围。

## 迁移

1. 检查向已有 `--host` 的命令继续追加该参数的启动脚本。删除被覆盖的旧参数以保持原来的单地址暴露范围；仅在确实需要每个监听器时保留多个参数。
2. 要同时启用两类回环，使用 `dsh web --host 127.0.0.1 --host ::1 --port 3080`。每个地址都必须属于本机，通配地址仍不支持。端口 0 只选择一个共享端口。
3. 自定义 WebServer 配置可保留 `host: 127.0.0.1`，也可替换成 `hosts: [127.0.0.1, '::1']`，但不能同时配置两个字段。
4. 确认诊断信息列出所有预期地址，且它们使用同一个端口。浏览器公开主机名仍需配置在 `--trusted-host` 中，Settings 授权仍需配置在 `--trusted-host-for-settings` 中；新增监听器不会自动加入公开主机名或授予 Settings 权限。
