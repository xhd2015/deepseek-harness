# Agent Note: 代理提供方设置

Status: implemented

English | [中文](2026-09-20-proxy-provider-settings.md)

## Problem

生成的本地代理路由需要适配器与模型编辑器共同使用的设置命名空间。即使代理负责上游认证，OpenAI 兼容请求仍要求非空客户端凭据。

## Decision

pi-ai 适配器在 `llm-proxy-providers` 下注册设置与模型发现。模型编辑器读取并写入该命名空间。包名、插件标识、组合行 id 和 `llm-pi-ai` 凭据记录作用域保留现有标识。用户自行迁移设置；旧设置命名空间没有别名。

## Alternatives considered

**仅重命名生成器输出。** 拒绝，因为 DSH 不会读取所生成的设置。

**随设置重命名凭据记录。** 拒绝，因为更改配置分节不需要移动已存储的登录信息。

**同时接受两个设置命名空间。** 拒绝，因为两个可写位置会引入当前需求并不需要的优先级和迁移行为。

## Consequences

提供方配置在设置文件、发现调用和模型编辑器中使用同一命名空间。现有登录信息保留其存储标识。现有设置文件需要手动迁移。Loader 组合测试与模型编辑器测试覆盖更新后的消费者。
